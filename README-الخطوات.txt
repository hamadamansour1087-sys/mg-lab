معمل محمد جمعه للأسنان — ملفات الرفع على GitHub Pages
======================================================
الخطوات كاملة بالصور الذهنية — من غير ولا أمر:

1) اعمل حساب مجاني على github.com (لو معندكش)
2) افتح:  github.com/new
3) Repository name اكتب:  mg-lab   — واختار Public — واضغط Create repository
4) في صفحة المستودع اضغط على الرابط:  "uploading an existing file"
5) فك ضغط ملف ZIP ده، واختار كل الملفات اللي جواه واسحبها في مربع الرفع
6) استنى شريط الرفع يخلص ثم اضغط الزر الأخضر:  Commit changes
7) من فوق في نفس الصفحة: Settings  ←  من القايمة اليسار Pages
   تحت Branch:  اختار  main   ثم اضغط Save
8) استنى دقيقة أو اتنين واعمل تحديث لصفحة Pages
   هيظهر في الأعلى رابط زي:  https://اسم-حسابك.github.io/mg-lab/
9) افتح الرابط ده من أي جهاز — البرنامج هيشتغل على طول

ملاحظات:
- أول نشر ممكن ياخد لحد 5 دقايق — لو الرابط قال 404 استنى وجرّب تاني
- البيانات نفسها: القاعدة السحابية واحدة — كل الأجهزة هتشوف نفس الحالات
- أي تحديث جديد: افتح المستودع، Add file ← Upload files، ارفع الملف الجديد
  بنفس الاسم (خاصة index.html) ثم Commit changes — الرابط مبيتغيرش
