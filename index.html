📄 سحب الأطباء من ملف Excel

سحب الأطباء بيتم عن طريق ملف Excel: اضغط «سحب من ملف Excel» واختر الشيت اللي فيه الأطباء — الأعمدة المطلوبة: اسم الطبيب، المحافظة، التليفون (اختياري). البرنامج بيكتشف الأعمدة تلقائيًا حتى لو الملف من غير عناوين، والمكرر يُتجاهل تلقائيًا. لو مش عارف شكل الملف، حمّل النموذج الجاهز واملأه. وتقدر كمان تلصق الأسماء نصًا في الصندوق — سطر لكل طبيب (مثال: د. أحمد سعيد - القاهرة - 01012345678).

🗃 نسخة احتياطية واستعادة

حمّل نسخة كاملة من كل بيانات المعمل (الحالات، الأطباء، الفنيين، الحضور). ملف JSON للاستعادة في أي جهاز، وملف Excel للأرشفة والاطلاع. الاستعادة بتضيف السجلات الجديدة وبتستبدل المطابق لها من غير ما تمسح أي حاجة تانية.

الأمان (Firestore Rules)

ارفع القواعد دي في Firebase Console → Firestore → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

للإنتاج الفعلي، استبدل true بشرط مصادقة حقيقي.
